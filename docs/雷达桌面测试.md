# 雷达桌面测试清单（主机接硬件，未上车）

> 当前阶段：把 LD2451 接到**主机（PC）**做 bring-up，**不需要电动车**。
> 目标：确认雷达通、数据对、把两个安全关键项标定掉（桌面就能做）。
> 完整上车流程见 [`硬件实测清单.md`](硬件实测清单.md)（之后再用）。

---

## 1. 接线（USB 转串口接到 PC）

- [ ] LD2451 **VIN→5V、GND→GND**；雷达 **TX→USB-TTL 的 RX、RX→TX**（交叉）。
- [ ] 雷达 IO 是 **3.3V**，USB-TTL 模块选 3.3V 电平的。
- [x] 个人Windows开发机真机串口已确认：COM5；当前这颗雷达波特率256000。
- [ ] DK2500串口路径尚未验证，上板后单独执行端口枚举与权限检查。

## 2. 看有没有数据（实时监视）

```
python scripts/monitor_radar.py --port COM5 --baud 256000
```
- [ ] 雷达前**挥手 / 走动**，应看到 `目标×N: [角度 距离 速度 接近/远离]` 刷新。
- [ ] 一直 `无目标` → 检查接线/串口号/供电；`无效帧` → 串口号或波特率不对。

> 提示：LD2451 默认只在有**运动**目标时输出（静止不动可能不报）；走动一下即可。

## 3. ★ 桌面就能做的两个安全标定（很重要，省得上车才发现反了）

- [x] **speed_dir（接近/远离）**：前向安装真机标定 `01=靠近`，接近输出负相对速度。
- [x] **角度坐标**：前向安装原始正角对应物理左侧，软件配置 `angle_sign=-1`，统一左负右正。
      *（手册表9与示例矛盾，这步必须实测确认，否则把接近当远离会漏报）*
- [ ] **角度左右符号**：站在雷达**右侧** → 监视器角度应为 **正(右)**；左侧为负。
      若与预期左右相反 → 融合配置 `flip_radar_angle=True`（上车对相机时用）。

## 4. 录一段数据（供离线调试）

```
python scripts/record_radar.py --port COM5 --baud 256000 --duration 30
```
- [ ] 录的时候在雷达前做几个动作（走近、左右移动），存成 `logs/radar_*.jsonl`。
- [ ] 回放检查：`python scripts/replay_radar.py --input logs/radar_xxx.jsonl`。

## 5.（可选）桌面端到端：USB 摄像头 + 雷达粗对齐

- [ ] 把一个 USB 摄像头和雷达**并排、朝同一方向**摆在桌上，对着走廊/门口。
- [ ] `detection.yaml` 的 `source` 改成摄像头编号（如 `0`），跑
      `python main_integrated.py --mode real --vision true --camera`。
- [ ] 有人从正前方走近时，看是否：检出目标、风险随距离上升、日志出现风险等级变化。
      *（桌面只是粗对齐，效果别太当真；正式效果测试要上车，见完整清单 §7）*
