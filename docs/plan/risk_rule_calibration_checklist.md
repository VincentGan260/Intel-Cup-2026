本文件只记录当前缺少实测依据、不得包装为最终安全参数的项目。外设到齐后统一按场景测试更新。

- [x] 每次输出记录独立的 `risk_decision_monotonic_ns`，并保存实际参与该次仲裁的各模态采集与处理完成时间。
- [x] 任一模态的采集或完成时间晚于决策时刻时拒绝参与，过期样本不得因“刚处理完成”重新变新。
- [x] 降级保持期间分别输出当前原始仲裁结果和上一有效风险的时间证据，不用新低风险样本冒充被保持的高风险来源。
- [x] 回放要求决策时间严格递增，并按记录时间驱动仲裁，不使用回放机器的当前墙上时间。
- [ ] DK2500 上测量相机、雷达、GPS 各自时钟来源和采集线程排队延迟，确认均转换到同一主机单调时钟域。

## 雷达风险边界

- [ ] 复核 `urgent_reference_s = 2.5`：含义仅为立即行动紧迫参考，不是完整制动时间。
- [ ] 复核 `attention_reference_s = 4.0`：重点统计过早提醒和漏掉有效提醒的次数。
- [ ] 测量完整的雷达采样到骑手可感知振动延迟 P95/P99；当前 `0.469 ms` 只覆盖解析完成到马达 GO。
- [ ] 复核 `point_gate_lateral_margin_m` 候选值 `0.015 / 0.025 / 0.035`。
- [ ] 记录所需减速度 `a_required`，但在完成车辆、制动和路面标定前不参与告警。

## 视觉行驶走廊

- [ ] 标定摄像头内参：焦距、主点和畸变参数。
- [ ] 测量摄像头安装高度、水平偏移和俯仰角。
- [ ] 确认摄像头实际水平/垂直视场角；当前水平 `90 deg` 只是待确认默认值。
- [ ] 用地面近、中、远距离标记验证 `body_width_m + lateral_margin` 的画面投影。
- [ ] 标定完成前只允许使用明确标记为临时参数的归一化透视梯形。
- [ ] 临时梯形基线：顶部 `0.40H`、顶部宽度 `0.10W`、底部宽度 `0.50W`、中心 `0.50W`。
- [ ] 临时视觉纵向参考：中风险辅助线 `y2/H = 0.61`，非常近辅助线 `y2/H = 0.82`；标定前不得解释为真实距离。
- [ ] 临时视觉扩张参考：`0.5 s` 窗口内线性尺寸增长 `12.5%` 对应约 `4 s` tau，增长 `20%` 对应约 `2.5 s` tau；至少3次有效观测。
- [ ] 临时时序关联参数：同类别、IoU不低于 `0.30`、历史跨度至少 `0.20 s`；检查漏关联、串轨和检测框抖动。
- [ ] 对路边护栏、停放车辆、路沿、宽路和弯道分别统计视觉路径误报/漏报。

- [x] 当前方案不计算GPS制动时间、停车距离或制动能力，不设置相关告警阈值。

## IMU

理论、公式、候选值身份和验收方法见`docs/plan/IMU横向失稳风险理论与标定方法.md`。以下所有未勾选数值均为实验搜索点，不是理论安全阈值。

- [x] 室内验证WT61C连通性、约100 Hz更新周期、三类帧同步、校验和及轴方向。
- [x] 确认横向主轴：左/右倾斜主要改变`roll`，对应角速度使用`gyro_x`。
- [x] 当前最终安装静止偏置为`roll0=-5.296°`、`pitch0=-1.493°`；重新安装后必须重测。
- [ ] 实现并验证`body_roll=roll-roll0`；正式IMU风险不得直接使用未校正的原始roll。
- [ ] IMU正式风险只负责“横向动态失稳前兆”，不负责障碍物风险；pitch暂不参与主风险通道。
- [ ] `30°/35°/40°`仅作为`roll_error_critical`实验搜索点；临界残差必须结合本车正常转弯、几何限制和受控失稳趋势数据确定。
- [ ] `15°/20°/25°`仅作为早期关注残差搜索点；必须基于正常转弯平衡倾角`phi_eq=k_turn*atan(v*yaw_rate/g)`校正后的`roll_error`分布标定，`k_turn`由左右稳定转弯确定。
- [ ] `10/15/20°/s`仅作为残差扩大速度搜索点；正式计算使用`outward_rate=sign(roll_error)*(gyro_x-derivative(phi_eq))`。
- [ ] 验证方向一致性：仅当`outward_rate>0`时视为偏离正常转弯平衡姿态；小于0表示正在恢复。
- [ ] `100/200/300 ms`仅作为中风险持续时间搜索点；正式值根据采样率、滤波相位延迟、颠簸误报和响应提前量确定。
- [ ] 连续3个有效样本仅作为高风险一致性搜索点；其时间跨度必须按真实采样时间戳计算，确认后立即升级。
- [ ] 定义并标定`tau_lean=(roll_error_critical-|roll_error|)/outward_rate`；`0.4/0.6/0.8 s`只作为搜索范围，不得照搬雷达TTC或宣称为安全时间。
- [ ] 实测`T_sensor_age_P99 + T_compute_to_motor_P99 + T_motor_to_perceptible_P99 + T_rider_corrective_response_quantile + margin`，据此确定高风险所需最小提前量。
- [ ] 高风险必须在到达失稳参考边界前触发，不能等严重倾斜或倒地后才首次报警。
- [ ] 已跌倒状态单独记录为`incident/fall_detected`，不作为“成功预警”的触发条件。
- [ ] 分别采集直线骑行、不同速度/半径的正常转弯、车身晃动、停止、坑洼冲击和安全可控的快速侧倾片段。
- [ ] `brake_score`和`bump_score`暂时只作为辅助诊断特征，不能单独触发IMU高风险。
- [ ] IMU失效或过期时输出unavailable/stale，不得当作level 0，也不得阻塞雷达和视觉预警。
- [ ] 根据实测更新周期和线程排队延迟P95/P99确定IMU stale阈值；当前`0.5 s`只属读取器完整性配置。
- [ ] IMU事件接入统一单调时钟，记录采集、完成和仲裁时间，满足`采集<=完成<=决策`。
