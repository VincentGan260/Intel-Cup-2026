# 离线风险场景验收基线

本文定义外设未齐、不能上车时的规则验收范围。它验证风险规则是否自洽，不用于证明参数已经完成实车标定，也不用于评估视觉模型的检测准确率。

自动化脚本：`scripts/test_warning_scenario_matrix.py`

## 当前固定边界

- 离散等级：低风险 `0`、中风险 `1`、高风险 `2`、不可判断 `unknown`。
- 连续风险值语义：干预紧迫度，不是事故概率。
- 中风险连续值边界：`0.35`。
- 高风险连续值边界：`0.70`。
- 雷达注意参考：`4.0 s + 0.469 ms`解析完成至马达GO延迟。
- 雷达紧迫参考：`2.5 s + 0.469 ms`解析完成至马达GO延迟。
- 风险升级：立即生效。
- 风险下降：连续保持 `500 ms` 后生效。
- 下降保持期间：对外等级、连续分数、告警原因和证据来源共同保持；当前传感器结果保存在 `raw_*` 字段。
- 同等级内连续分数可正常变化；全部告警模态失效时立即输出 `unknown + None`。
- 时间契约：拒绝未来时间戳、完成早于采集的时间戳、超过时效窗口的事件以及晚到的旧序列；设备恢复后的新事件立即重新参与融合。
- 雷达快速高风险通道在写入状态和驱动马达前执行同一时间契约，不等待视觉、GPS或IMU。
- 每次结果以 `risk_decision_monotonic_ns` 表示决策时刻，并输出各可用模态的采集时间、完成时间及相对决策时刻的年龄。
- 正常结果采用 `as_of_latest_fresh` 语义：表示决策时刻使用各模态当时最新且未过期的数据，不宣称不同硬件在物理上同时采样。
- 下降保持结果采用 `downgrade_held` 语义，并保留原告警证据时间；不得把保持中的旧证据标成当前新测量。
- GPS速度：只修正视觉单帧接近度，不改变离散等级。
- 模态分数契约：等级0对应 `[0, 0.35)`，等级1对应 `[0.35, 0.70)`，等级2对应 `[0.70, 1.00]`。
- 分数与等级矛盾时保留离散等级，将分数限制到对应区间并记录契约状态；缺失或非数值分数使用该等级的最低边界回退。

## 场景预期

| 场景 | 预期等级 | 预期状态 | 核心检查 |
|---|---:|---|---|
| 空旷道路 | 0 | normal | 连续值接近0，无告警事件 |
| 雷达TTC刚大于注意边界 | 0 | normal | 连续值低于0.35 |
| 雷达TTC位于注意边界 | 1 | normal | 连续值从0.35开始 |
| 雷达TTC位于紧迫边界 | 2 | normal | 连续值从0.70开始 |
| 路径点门外的接近目标 | 0 | normal | 不进入路径候选 |
| 路径点门内的静止目标 | 0 | normal | 相对速度不接近，不计算TTC风险 |
| 视觉中风险，GPS 30 km/h | 1 | normal | 连续值温和上升但低于0.70 |
| 视觉中风险，GPS失效 | 1 | normal | GPS系数回到1.0，视觉值不变 |
| 雷达失效，视觉tau高风险 | 2 | degraded | 视觉仍可独立输出高风险 |
| 雷达高风险，视觉低风险 | 2 | normal | 视觉不能否决雷达 |
| 雷达中风险，视觉高风险 | 2 | normal | 采用可用模态最大等级和最大连续值 |
| 雷达与视觉均失效 | unknown | unknown | 不得显示为低风险0 |
| 雷达与视觉均过期 | unknown | unknown | 不得沿用过期结果 |
| 风险由0升级到2 | 2 | - | 立即升级，不等待保持时间 |
| 风险由2下降到0不足500 ms | 2 | - | 保持原等级 |
| 风险由2下降到0达到500 ms | 0 | - | 完成降级 |

## 运行与记录

```powershell
python scripts/test_warning_scenario_matrix.py
```

脚本会输出实际等级、连续风险值、系统状态和原因。任一结果不符合当前规则基线时会直接断言失败。

上车后应保留相同的场景名称和验收字段，把合成事件替换为录制的雷达、视觉和GPS数据。实车标定只允许按“单参数修改、重复场景复测、保留或回退”的流程更新本表。

## 当前限制

- 视觉中高风险场景从视觉规则输出事件开始测试，不代表检测模型一定能识别真实障碍物。
- 侧面目标场景验证的是当前点门和接近条件，不代表道路边缘已经完成标定。
- GPS速度系数和时效阈值仍需根据真实更新周期及道路片段复核。
- IMU已通过`scripts/test_imu_warning_rule.py`单独覆盖正常转弯补偿、中高风险边界和GPS降级；本矩阵尚未合并这些IMU场景。
