## 3. 必须记录的字段

以CSV或JSONL连续记录，不能只截图终端：

```text
wall_timestamp
monotonic_timestamp_ns
valid
roll, pitch, yaw
gyro_x, gyro_y, gyro_z
acc_x, acc_y, acc_z
brake_score, bump_score, tilt_score
```

若修改读取器，额外记录角度包、角速度包、加速度包各自的最后到达时间和样本年龄。不要把缺失字段自动写成“有效的0”。

## 4. 受控动作

每个场景开始和结束保持静止3秒，动作缓慢，确保车辆有人扶稳：

1. [x] 水平静止。
2. [x] 缓慢向左、向右倾斜并恢复。
3. [x] 缓慢前倾、后仰并恢复。
4. [x] 保持车体基本竖直，向左、向右转动车头。
5. [x] 轻微上下振动或模拟小颠簸。
6. [ ] 直线推行及正常骑行。
7. [ ] 不同速度和半径的普通转弯，覆盖入弯、稳定转弯、出弯回正。
8. [ ] 正常减速、停止和安全可控的较急减速。
9. [ ] 有人扶车条件下模拟快速侧倾趋势；不做无人保护的故意摔车测试。

同步记录每段动作的开始时间、结束时间、方向和人工备注。
