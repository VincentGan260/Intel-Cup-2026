# 自采数据采集说明

## 目的

自采数据用于：
- 最终模型验证（最接近真实部署场景）
- 少量模型微调
- INT8 量化校准

## 采集设备要求

### 摄像头
- 分辨率：至少 1080p
- 帧率：30fps 或更高
- 视角：车把视角，镜头朝前略向下
- 安装位置：车把中央或头盔

### 存储
- 录制格式：MP4/H.264
- 建议使用高速存储卡

## 采集场景清单

### 必采场景
| 场景类型 | 描述 | 目标数量 |
|---------|------|---------|
| 白天正常道路 | 常规城市道路骑行 | 100 帧 |
| 傍晚/弱光 | 日落前后低光照 | 50 帧 |
| 逆光 | 太阳直射镜头 | 50 帧 |
| 路口行人横穿 | 斑马线行人 | 50 帧 |
| 前方电动车/自行车 | 非机动车目标 | 50 帧 |
| 前方机动车 | 汽车、公交车等 | 50 帧 |

### 补充场景
| 场景类型 | 描述 | 目标数量 |
|---------|------|---------|
| 路边停车遮挡 | 车辆停在路边 | 30 帧 |
| 颠簸运动模糊 | 不平整路面 | 30 帧 |
| 障碍物逼近 | 近距离目标 | 30 帧 |
| 前车急停 | 突发刹车场景 | 20 帧 |

## 视频采集规范

### 每段视频要求
- 时长：30 秒 ~ 2 分钟
- 内容：包含至少一种目标场景
- 环境：记录天气、光照条件

### 采集注意事项
1. 遵守交通规则，确保安全
2. 保持稳定，避免剧烈抖动
3. 镜头保持清洁
4. 记录 GPS 坐标和时间

## 抽帧规则

### 工具
使用 OpenCV 或 FFmpeg 抽帧

### 抽帧策略
```bash
# 普通视频：每秒抽 1 帧
ffmpeg -i input.mp4 -r 1 frames/%04d.jpg

# 行人横穿/前车急停：每秒抽 3～5 帧
ffmpeg -i input.mp4 -r 5 frames/%04d.jpg
```

### 筛选标准
- 删除模糊严重的帧
- 删除重复度过高的连续帧
- 删除没有有效道路信息的帧
- 保留关键帧（行人出现、车辆变道等）

## 数据组织

### 目录结构
```
rider_self_collected/
├── videos/           # 原始视频
│   ├── day_01.mp4
│   ├── dusk_01.mp4
│   ├── night_01.mp4
│   └── ...
├── frames/           # 抽帧图片
│   ├── day_01/
│   │   ├── 0001.jpg
│   │   ├── 0002.jpg
│   │   └── ...
│   └── ...
└── annotations/      # 标注文件（可选）
    ├── day_01.json
    └── ...
```

### 文件命名规范
```
{scene_type}_{sequence_number}.mp4
{scene_type}_{sequence_number}/{frame_number}.jpg

scene_type: day, dusk, night, backlight, crosswalk, etc.
sequence_number: 01, 02, 03...
frame_number: 0001, 0002, 0003...
```

## 标注指南（可选）

### 目标检测标注
标注以下类别：
- person（行人）
- bicycle（自行车）
- motorcycle（摩托车）
- car（小汽车）
- bus（公交车）
- truck（卡车）

### 标注格式
使用 COCO 格式或 YOLO 格式

## 安全提示

1. 采集时务必遵守交通规则
2. 优先保证骑行安全
3. 避免在繁忙路口长时间停留
